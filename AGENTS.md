# Omarchy Marketplace Guidelines

- **Plugin Verification Updates:** When submitting an update/verification to an already-listed plugin in the `omacom/omarchy-plugin-marketplace` repository, do not use the new-submission form. Instead, open a **Verify** ticket (via the `verify-plugin.yml` template or by creating a verification issue titled `[Verify]: <plugin-id> — publish <version>` referencing your updated tag/commit).
